INTRODUCTION

Is ebook ka maqsad

Is ebook ka maqsad ek hi hai: aap n8n se ek chhote gym ke liye working Gym Manager Automation bana sako, aur use ek paid service ki tarah gym owners ko bech sako.

Reel mein promise tha ki naya member Google Sheet mein khud save hoga, expiry se pehle WhatsApp reminder jayega, payment status khud update hoga, aur owner ko daily report milegi. Yeh ebook un chaaron cheezon ko ek ke baad ek build karna sikhata hai.

Yeh ebook theory nahi hai. Har chapter mein pehle batate hain ki cheez kya hai, kyun chahiye, kaise kaam karti hai, phir exact steps aur copy-paste examples dete hain.

Yeh ebook kiske liye hai

  • Beginners jinhone kabhi automation nahi banayi, par Google Sheets kholna aata hai.
  • Freelancers jo local businesses (gym, coaching, salon) ko automation service bechna chahte hain.
  • Gym owners ya managers jo apna member tracking system khud set karna chahte hain.

Coding aana zaroori nahi hai. Kuch chhote JavaScript snippets aur Google Sheet formulas diye gaye hain, jo bas copy-paste karne hain.

Aap kya seekhoge

  • Gym ke members, fees aur expiry ke liye ek clean Google Sheet design karna.
  • n8n mein 4 workflows banana: member entry, expiry reminder, payment update, daily report.
  • WhatsApp par message bhejne ke options aur unke trade-offs samajhna.
  • Workflow ko test karna aur galti hone par pata lagana.
  • Gym owner ko demo dena, proposal banana aur setup fee (10 se 15 hazaar rupaye) justify karna.

Is ebook ko kaise use karein

Chapters ko order mein follow karo, kyunki har workflow pichle wale ke Google Sheet par chalta hai. Pehle apne liye ek dummy gym banao (5 se 10 fake members), poora system test karo, aur tabhi kisi asli gym owner ko dikhao. Jahan pricing, plan limits ya platform rules ki baat hai, wahan source link diya hai; ye cheezein badalti rehti hain, isliye use karne se pehle official page ek baar check kar lena.

Zaroori note: Is ebook mein kisi kamaai, client ya result ki guarantee nahi hai. 10 se 15 hazaar rupaye ek realistic setup fee ka example hai, jo aapke area, skill aur gym ke size par depend karta hai.

CHAPTER 01

Reel ka promise aur poora system ek nazar mein

Gym Manager Automation ka kaam ek line mein: member data Google Sheet mein rakho, n8n us sheet ko roz check kare, aur jo kaam owner haath se karta tha (reminder, status update, report) woh khud ho jaaye.

Gym owner ki asli problem

100 se 150 members wale gym mein har member ki joining date, plan, fees aur renewal date alag hoti hai. Register ya Excel mein yeh sab haath se dekhne par do cheezein hoti hain: roz ka time jaata hai, aur kisi ki renewal chhoot jaati hai, matlab owner ka paisa. Automation isi ek problem ko solve karta hai, isliye owner ke liye iski value clear hai.

System kaise kaam karta hai

Poore system mein 3 cheezein hain: Google Sheet (database), n8n (jo kaam chalata hai) aur WhatsApp (member tak message pahunchane ke liye). Isme 4 alag workflows hain:

  1. Workflow 1, Member Entry: form ya webhook se naya member aata hai, n8n use Google Sheet mein ek nayi row bana deta hai.
  2. Workflow 2, Expiry Reminder: n8n roz subah sheet padhta hai, jin members ki expiry paas hai unhe WhatsApp template message bhejta hai.
  3. Workflow 3, Payment Update: member payment kare to payment platform n8n ko batata hai, n8n sheet mein status "Paid" kar deta hai aur membership ki nayi expiry date set karta hai.
  4. Workflow 4, Daily Report: n8n roz ek fixed time par active, expired aur pending members gin kar owner ko WhatsApp ya email par summary bhej deta hai.

Kya verified hai, kya recommendation hai

  • Verified (official docs): n8n mein Schedule Trigger, Google Sheets Trigger aur WhatsApp Business Cloud node maujood hain. WhatsApp node mein "Send Template" operation hai. Razorpay Payment Links ke liye payment_link.paid webhook event hota hai. Sources end mein hain.
  • Recommendation (mera suggested design): sheet ke columns, status ke naam, message wording, aur 4 workflows ka split. Aap apne gym ke hisaab se badal sakte ho.
  • Badal sakne wali cheezein: n8n aur WhatsApp ke prices aur rules. Inhe use karne se pehle official page par check karo.

CHAPTER 04 · WORKFLOW 1

Naya member Google Sheet mein khud save

Yeh workflow ek online form se member ki details leta hai, expiry date nikalta hai aur Members tab mein row bana deta hai. Front desk par ek tablet ya phone par yeh form khula rakha ja sakta hai.

Workflow ka flow

n8n Form Trigger→Code→Google Sheets (Append or Update Row)

Yeh teen nodes kaafi hain. Aap chaho to end mein ek WhatsApp (Send Template) node jodkar welcome message bhi bhej sakte ho.

Step by step

  1. n8n mein New Workflow banao, naam rakho "1 - New Member Entry".
  2. Form Trigger node add karo. Form title "Gym Registration" rakho aur yeh fields banao: Name (text), Phone (text), Plan (dropdown: Monthly, Quarterly, Half-yearly, Yearly), Fee (number), Start Date (date).
  3. Code node add karo, mode "Run Once for All Items" rakho, aur neeche wala code paste karo.
  4. Google Sheets node add karo. Operation "Append or Update Row" chuno, apni Gym Manager sheet aur Members tab select karo. Mapping mode "Map Each Column Manually" rakho aur "Column to match on" mein phone chuno. Isse ek hi number do baar entry hone par duplicate row nahi banegi.
  5. Har column ke saamne Code node ka matching field map karo (member_id, name, phone, plan, plan_months, fee, start_date, expiry_date, payment_status).
  6. Form ko test karo: ek test member bharo, Sheet kholkar row check karo.
  7. Sab sahi hone par workflow ko publish/activate karo. Form ka production URL alag hota hai; woh URL gym ke front desk ke browser mein bookmark kar do.

Code node ka code (copy-paste)

Yeh code phone number ko 91 wale format mein badalta hai, plan se months nikalta hai aur expiry date calculate karta hai (mahine ke aakhri din ka dhyan rakhte hue, jaise 31 January plus 1 month = 28 February).

Code node · JavaScript
const planMonths = { 'Monthly': 1, 'Quarterly': 3, 'Half-yearly': 6, 'Yearly': 12 };

function addMonths(isoDate, months) {
  const [y, m, d] = isoDate.split('-').map(Number);
  const total = (m - 1) + months;
  const ny = y + Math.floor(total / 12);
  const nm = total % 12;
  const lastDay = new Date(Date.UTC(ny, nm + 1, 0)).getUTCDate();
  const nd = Math.min(d, lastDay);
  return ny + '-' + String(nm + 1).padStart(2, '0') + '-' + String(nd).padStart(2, '0');
}

return $input.all().map(item => {
  const f = item.json;
  let phone = String(f['Phone']).replace(/\D/g, '');
  if (phone.length === 10) phone = '91' + phone;
  const months = planMonths[f['Plan']] || 1;
  const start = String(f['Start Date']).slice(0, 10);
  return {
    json: {
      member_id: 'GYM-' + String(Date.now()).slice(-6),
      name: f['Name'],
      phone: phone,
      plan: f['Plan'],
      plan_months: months,
      fee: f['Fee'],
      start_date: start,
      expiry_date: addMonths(start, months),
      payment_status: 'Pending'
    }
  };
});

Agar aapke form ke field names alag hain (jaise "Full Name"), to code mein f['Name'] jaisi lines ko usi naam se badal do. n8n ke field names form ke label se hi aate hain.

Pehle se bane members ka kya: gym ke purane 100 se 150 members ek baar Excel se copy karke seedha Members tab mein paste kar do (same 11 columns, same date format). Workflow 1 sirf naye members ke liye hai.

Alternative: agar owner Sheet mein hi row type karna chahta hai, to Google Sheets Trigger node use karo (events: Row added, Row updated, Row added or updated). Phir nayi row aate hi aap welcome message ya doosre steps chala sakte ho.

CHAPTER 05 · WORKFLOW 2

Expiry se pehle WhatsApp reminder

Yeh workflow roz subah ek baar chalta hai, Sheet padhta hai, jin members ki expiry paas hai unhe WhatsApp template message bhejta hai, aur Sheet mein likh deta hai ki reminder aaj gaya.

Workflow ka flow

Schedule Trigger→Google Sheets (Get Row(s))→Code (filter)→WhatsApp (Send Template)→Google Sheets (Update Row)

Pehle WhatsApp template banao

WhatsApp par business-initiated message (jo member ne pehle message nahi kiya ho) sirf approved template se bheja ja sakta hai. Isliye Meta ke WhatsApp Manager mein ek template banao aur approval ka wait karo. Ek example text:

WhatsApp template · Utility
Namaste {{1}}, aapki gym membership {{2}} ko khatam ho rahi hai. Renew karne ke liye gym par aayein ya hamse sampark karein. Dhanyavaad!

Isme {{1}} member ka naam hai aur {{2}} expiry date. Template ko "Utility" category mein submit karo, kyunki yeh ek existing membership ke baare mein update hai. Dhyan rakho: category Meta tay karta hai aur woh isse Marketing mein bhi badal sakta hai, jiska rate zyada hota hai (Chapter 2 mein example hai). Template mein koi offer ya discount mat daalo, warna Marketing mein jaane ka chance badh jaata hai.

Opt-in: member se pehle consent lena zaroori hai ki gym use WhatsApp par messages bhejega. Chapter 4 ke form mein ek checkbox "Mujhe WhatsApp par membership updates chahiye" jod do, aur sirf unhi ko message bhejo.

Step by step

  1. Naya workflow banao: "2 - Expiry Reminder".
  2. Schedule Trigger add karo: interval "Days", roz subah 9 baje. Workflow ki timezone Asia/Kolkata set karo, nahi to reminder ghante-aadha ghanta aage-peeche ho sakta hai. Dhyan rakho: schedule wala workflow tabhi chalta hai jab woh publish/activate ho.
  3. Google Sheets node add karo, operation "Get Row(s)", Members tab, filter ke bina (saari rows).
  4. Code node add karo aur neeche wala filter code paste karo.
  5. WhatsApp node add karo: resource "Message", operation "Send Template". Apna sender phone number select karo, recipient mein {{ $json.phone }}, template wahi jo approve hua, aur body ke parameters mein pehle {{ $json.name }} phir {{ $json.expiry_date }} daalo. Parameters ka order template ke order jaisa hi hona chahiye, nahi to "invalid parameter" error aata hai.
  6. Google Sheets node (Update Row) add karo: phone se row match karo aur last_reminder_date mein aaj ki date likho: {{ $now.setZone('Asia/Kolkata').toFormat('yyyy-MM-dd') }}.
  7. Sheet mein testing ke liye ek row ki expiry aaj se 3 din baad ki rakho aur workflow ko manually Execute karke dekho.

Filter code (copy-paste)

Yeh code sirf unhi members ko aage bhejta hai jinki expiry 3 din baad ya aaj hai, aur jinhe aaj reminder pehle nahi gaya. Agar koi match nahi hota, to aage ke nodes chalte hi nahi, isliye khali din par koi message nahi jaata.

Code (filter) · JavaScript
const REMIND_DAYS = [3, 0]; // expiry se kitne din pehle reminder bhejna hai
const today = new Date().toLocaleDateString('en-CA', { timeZone: 'Asia/Kolkata' });

function toUtc(iso) {
  const [y, m, d] = iso.split('-').map(Number);
  return Date.UTC(y, m - 1, d);
}

return $input.all().filter(item => {
  const r = item.json;
  if (!r.expiry_date || !r.phone) return false;
  if (r.last_reminder_date === today) return false;
  const daysLeft = Math.round((toUtc(r.expiry_date) - toUtc(today)) / 86400000);
  return REMIND_DAYS.includes(daysLeft);
});

en-CA locale isliye use kiya hai kyunki woh date ko YYYY-MM-DD format mein deta hai, jo humari Sheet ke format se match karta hai.

Reminder ka timing kaise tay karein

  • 3 din pehle aur expiry wale din: zyadatar gyms ke liye kaafi hai. REMIND_DAYS = [3, 0] rakho.
  • Zyada reminder se bacho: har member ko mahine mein 2 se zyada message bhejne se member irritate ho sakte hain. Kuch log message ko spam report kar dete hain, jisse number ki quality kharab ho sakti hai.

Is chapter ka action

  • WhatsApp template submit karo aur approval ka wait karo.
  • Workflow ke 5 nodes jodo.
  • Apne number se test row banao aur reminder receive karke dekho.
  • Dobara chalane par check karo ki same din dusra message nahi gaya.
CHAPTER 06 · WORKFLOW 3

Payment hote hi status khud update

Jaise hi member payment kare, Sheet mein payment_status Paid ho jaata hai, last_payment_date bhar jaati hai, aur renewal hone par expiry date aage badh jaati hai. Iske do raaste hain: online payment (Razorpay webhook) aur cash/UPI (owner ek chhota form bharta hai). Dono ka aakhri hissa same hai.

Pehle Sheet mein ek column jodo

Members tab mein 12th column last_payment_ref jodo. Isme payment link ki ID save hogi, taaki payment platform ek hi event do baar bheje (retry) to expiry do baar aage na badhe.

Raasta A: Razorpay Payment Link (online payment)

Webhook→IF→Code (extract)→Google Sheets (Get Row(s))→Code (compute)→Google Sheets (Update Row)

Kaise kaam karta hai: gym har member ke liye Razorpay Payment Link banata hai aur uska reference_id wahi rakhta hai jo Sheet mein member_id hai (jaise GYM-123456). Jab member link se payment karta hai, Razorpay payment_link.paid event bhejta hai. Is event ke payload mein payment link ka reference_id aur status aata hai, isse hum sahi member ki row dhoondh lete hain.

  1. n8n mein workflow banao: "3 - Payment Update". Webhook node add karo: method POST, aur isse milne wala Production URL copy karo.
  2. Razorpay Dashboard mein Account & Settings, phir Webhooks mein jao, naya webhook banao, wohi URL daalo aur sirf payment_link.paid event select karo.
  3. Webhook secret set karo. Webhook ko asli use karne se pehle signature verify karo, kyunki warna koi bhi us URL par fake request bhejkar kisi ko Paid mark kar sakta hai. Razorpay signature header mein bhejta hai, aur use verify karne ke liye raw request body chahiye hota hai, parsed JSON nahi. Webhook node ke options mein Raw Body on karke Crypto node se HMAC SHA256 nikaalo aur header se compare karo. Poora process Razorpay ke official webhook docs mein diya hai (sources dekho).
  4. IF node mein condition lagao: event barabar payment_link.paid.
  5. Code (extract) node ka naam "Extract Payment" rakho aur yeh code paste karo:

  expiry_date: newExpiry,
  last_payment_ref: pay.link_id
}}];
  1. Google Sheets (Update Row): member_id se row match karo aur payment_status, last_payment_date, expiry_date, last_payment_ref ko Code node ke fields se map karo.
  2. Test karne ke liye Razorpay ka test mode use karo, ek test payment link banao aur payment karke Sheet check karo. Aise test ke liye alag test member row rakho, asli member par test mat karo.

Payment Link kaise banta hai (dashboard se ya API se), iske liye Razorpay ke official Payment Links docs dekho. Dhyan rakho: payment ka paisa seedha gym ke Razorpay account mein jaata hai, aapke paas nahi.

Raasta B: cash ya UPI (owner khud confirm kare)

Agar gym online payment link use nahi karta, to Form Trigger se ek "Record Payment" form banao jisme member ka phone, amount aur payment mode (Cash, UPI) ho. Form submit hone par n8n phone se member ki row dhoondhta hai aur wahi "compute" code aur "Update Row" node chalata hai (compute code mein pay.link_id ki jagah ek khud ki ID, jaise 'manual-' + Date.now(), rakh do). Is tarah owner ko Sheet kholkar haath se status badalna nahi padta, sirf ek form bharna padta hai.

Is chapter ka action

  • Members tab mein last_payment_ref column jodo.
  • Raasta A ya B mein se jo gym ke hisaab se ho, woh banao.
  • Test payment karke dekho ki status Paid hua aur expiry sahi aage badhi.
  • Same event dobara bhejkar dekho ki expiry dusri baar aage nahi badhti.
CHAPTER 07 · WORKFLOW 4

Owner ke liye daily report

Yeh workflow roz ek fixed time par Sheet padhta hai, active, expired aur pending payments gin kar owner ko summary bhej deta hai. Owner ko register ya spreadsheet kholne ki zaroorat nahi padti.

Teen counts ki definition

Report se pehle yeh tay kar lo ki teeno ka matlab kya hai, taaki owner aur system dono ek hi cheez gine:

CountMatlabSheet ka rule
ActiveMembership chal rahi haiexpiry_date aaj ya aaj ke baad ki hai
ExpiredMembership khatam ho chuki, renewal baaki haiexpiry_date aaj se pehle ki hai

Workflow ka flow

Schedule Trigger→Google Sheets (Get Row(s))→Code→Gmail ya WhatsApp

Step by step

  1. Naya workflow banao: "4 - Daily Report". Schedule Trigger mein roz subah 8 baje (ya raat 9 baje) set karo, timezone Asia/Kolkata.
  2. Google Sheets (Get Row(s)) se Members tab ki saari rows lo.
  3. Code node mein neeche wala code paste karo.
  4. Report bhejne ka tareeka chuno (neeche dono hain). Workflow publish/activate karo.

Code (copy-paste)

Daily report · JavaScript
const today = new Date().toLocaleDateString('en-CA', { timeZone: 'Asia/Kolkata' });
const rows = $input.all().map(i => i.json).filter(r => r.member_id);

const active  = rows.filter(r => r.expiry_date >= today);
const expired = rows.filter(r => r.expiry_date && r.expiry_date < today);
const pending = rows.filter(r => r.payment_status === 'Pending');

const names = list => list.length ? list.map(r => r.name).join(', ') : 'Koi nahi';

const text =
  'Gym report ' + today + '\n' +
  'Active members: ' + active.length + '\n' +
  'Expired memberships: ' + expired.length + ' (' + names(expired) + ')\n' +
  'Pending payments: ' + pending.length + ' (' + names(pending) + ')';

return [{ json: {
  date: today,
  active: active.length,
  expired: expired.length,
  pending: pending.length,
  text
}}];

Report bhejne ke do tareeke

Tareeka 1: Email (sabse aasan). Gmail node (ya Send Email node) jodo, recipient mein owner ka email daalo, subject mein Gym report {{ $json.date }} aur message mein {{ $json.text }}. Isme member ke naam bhi aate hain, aur kisi WhatsApp template ki zaroorat nahi.

Tareeka 2: WhatsApp. Owner ko report bhejne ke liye bhi approved template chahiye (jab tak owner ne pichle 24 ghante mein aapke business number ko message nahi kiya ho). Template body parameters mein new line allowed nahi hoti, isliye ek line ka template banao, jaise:

WhatsApp template · owner report
Gym report {{1}}: Active {{2}}, Expired {{3}}, Pending payments {{4}}. Poori list Sheet ke Dashboard tab par dekhein.

Phir WhatsApp node (Send Template) mein parameters {{ $json.date }}, {{ $json.active }}, {{ $json.expired }}, {{ $json.pending }} is order mein daalo. Isme sirf counts jaate hain; naam wali list owner Sheet ya email mein dekh sakta hai.

Mera suggestion: shuru mein email wala tareeka lagao (kam setup, kam cost) aur owner jab WhatsApp maange tab Tareeka 2 jodo.

CHAPTER 08

Testing, errors aur data privacy

Client ko system dene se pehle har workflow ko jaan-bujhkar todkar dekho. Ek galat reminder ya galat Paid status owner ka bharosa turant tod deta hai.

Testing ka sahi tareeka

  1. Alag test Sheet rakho: poora system pehle ek dummy Sheet par chalao jisme sirf aapke ya aapke doston ke numbers hon.
  2. Edge cases test karo: 31 January wali join date, ek hi phone dobara, expire ho chuka member jo payment karta hai, ek payment event do baar aana, aur khali phone wali row.
  3. Manual Execute pehle, schedule baad mein: schedule wale workflow ko pehle "Execute workflow" se haath se chalao, aur output har node par dekho.
  4. Production URL alag hai: Form aur Webhook nodes ka Test URL aur Production URL alag hote hain. Client ko hamesha Production URL do, aur workflow publish/activate karna mat bhoolo.

Galti hone par pata kaise chale

n8n mein ek alag workflow banao jiska pehla node Error Trigger ho, aur uske baad ek email ya WhatsApp message jo aapko batae ki kaunsa workflow fail hua. Phir har production workflow ki Settings mein is error workflow ko Error Workflow ke roop mein chuno. Nodes ki setting mein "Continue on Fail" tabhi on karo jab aap jaan-bujhkar chahte ho ki ek row fail hone par baaki rows chalti rahein. Mera suggestion: reminder wale workflow mein yeh on rakho, taaki ek member ka galat number baaki sabke reminder na rok de.

Data privacy aur WhatsApp rules

Members ka naam aur phone number personal data hai. Kuch basic niyam jo har project mein follow karo:

  • Sheet gym owner ke account mein rahe, aur sirf zaroori logon ke saath share ho. Public link sharing kabhi on mat karo.
  • Consent lo: member se WhatsApp messages ke liye likhit ya form ke through sahmati lo, aur jo member message band karwana chahe use list se hata do.
  • Sirf zaroori data rakho: is system ko health details, ID proof jaisi cheezein rakhne ki zaroorat nahi hai.
  • Kanoon ka dhyan: India mein personal data par Digital Personal Data Protection Act, 2023 lagu hota hai. Main lawyer nahi hoon, isliye client ke liye privacy notice aur consent ke wording ke liye kisi vakil se salah lo.
  • Meta ke rules follow karo: template mein sirf sahi category ka content daalo, aur spam jaisa bhej-bhej kar number ki quality kharab mat karo.

FAQs

Kya coding aani zaroori hai?

Nahi. Is ebook mein kuch chhote JavaScript snippets hain jo copy-paste karne hain. Bas field ke naam apne form ke hisaab se milane honge.

Kya bina WhatsApp API ke reminder bhej sakte hain?

Haan, email ya SMS ke zariye. Par is ebook ka promise WhatsApp reminder hai, aur uska official raasta WhatsApp Business Platform hai. Unofficial tareekon se number ban hone ka khatra hota hai.

Ek gym ke liye n8n ke kitne executions lagenge?

Workflow 2 aur 4 roz ek-ek baar chalte hain (lagbhag 60 executions per month), baaki member ki activity par depend karta hai. Zyadatar chhote gyms ke liye Starter plan ki limit kaafi rehni chahiye, par apna hisaab khud lagao.

Agar owner Excel hi use karna chahe to?

Google Sheet ko hi uska Excel samjhao; woh ek browser mein khulti hai aur owner ke phone par bhi dekh sakta hai. Purana Excel data copy karke Members tab mein paste kar do.

Kya 10 se 15 hazaar rupaye pakka milenge?

Nahi, yeh ek example hai. Charge aapke kaam, area aur client par depend karta hai.
